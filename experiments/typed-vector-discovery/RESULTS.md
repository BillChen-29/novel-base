# 分类型检索与本地向量实验

日期：2026-10-28。代码与结果保存在 novel-base 内；本轮没有构建界面。

## 结果

本轮跑通了“完整前文 → 多路检索 → 按资料类型取候选 → 原文证据审核 → 下一步提案”。按类型筛选后，抽象查询的向量和混合检索各找回 1 条有依据的候选，关键词检索没有找回。但这仍不足以证明推荐机制可靠：全部 72 个案例—资料配对中，仅有 2 个得到当前结构支持，而且它们来自同一段对话在两个截点中的表现。

没有任何配对被确认属于母题的特定片段。两个得到支持的配对都是“对话张力”情境；其中只有较早截点有本轮提出的下一步方案。当前结果支持继续细化数据和事件状态，尚不能选定最佳模型或宣布自动母题推荐成功。

## 固定输入与比较方式

- 沿用上一轮 26 份资料、4 个真实小说截点、2 个原创对照及 12 条抽象查询。没有根据新结果改写查询或调整权重。
- 真实截点来自两段各有前后截点的顺叙片段，原创对照也是同一场景的前后截点；它们不是 6 个独立故事样本。当前查询和材料也不是新划分的盲测集。
- 26 份资料中，12 份母题／情境作为主要评审池，另外 14 份为技巧、风格、人物、节奏资料。评审员阅读每个案例对应的全部 12 份资料全文，共 72 个配对，不只审核检索返回的前三名。
- 两名当前 AI 分别审核前、后截点，各自看不到配对的另一截点、查询、检索分数和排名；另两名 AI 按同一分组独立复核。最终裁定保留在 [adjudication.json](adjudication.json)。这些是 AI 判断，没有人类金标准。
- 关键词统计基于完整 26 份语料。每条查询先排完所有文档，再按类型筛选并取前三名；未将全局前三名直接过滤冒充分类检索。混合检索中两路等权，抽象查询组内也等权。
- 使用已安装的 EmbeddingGemma 300M Q8_0，经本地 QMD 格式函数和 node-llama-cpp 编码。339 个独立资料片段、6 段完整前文、12 条查询，共 357 个输入，768 维。原文未被截短，全部通过输入长度检查；未调用额外模型接口、下载模型或改动用户 QMD 索引。
- 前一轮原文／抽象查询的关键词全局前三名，在全部 12 项对比中保持一致。

## 找回了什么

“得到结构支持”要求故事与知识原文之间存在具体关系，并且当前视角能使用所依据的信息。分数本身不会放行候选。

| 检索方法 | 全局前三名中的结构支持配对 | 母题／情境分类前三名中的结构支持配对 | 分类结果中的下一步方案 |
|---|---:|---:|---:|
| 原文＋关键词 | 0 | 0 | 0 |
| 抽象查询＋关键词 | 0 | 0 | 0 |
| 原文＋向量 | 0 | 0 | 0 |
| 抽象查询＋向量 | 0 | 1 | 1 |
| 原文＋关键词／向量混合 | 0 | 0 | 0 |
| 抽象查询＋关键词／向量混合 | 0 | 1 | 1 |

每格检索预算均为每例 3 个位置，6 例共 18 个位置。完整母题／情境池有 2 个已确认的结构配对，所以两条成功路线在此池内各找回 1/2；四个无阳性的案例，召回率记录为 null。全局结果中其他类型仍是“未评审”，不是错误或无用资料，因此表中的 0 不能解释为全部创作建议都无效。

最终标签为：当前结构 2、特定片段 0、证据不足 70、直接矛盾 0。证据不足不等于资料永远无关。这个小池的配对数与上一轮“局部写作操作可用”统计采用不同判定范围，不能直接比较成功率。

## 可检查的承接结果

real-03 的前文已有一段互动：一方要求对方在外人面前克制情绪，另一方调整表情，却通过回应显露抵触。它能对应“对话张力”资料中的表面表达、真实态度与关系冲突。

本轮提案是：在已完成交接、外人离开之后，人物安置刚收到的物品，同时继续讨论应当表现出何种态度。只延续前文已有分歧，没有把新设定写成既有事实。抽象查询向量路线和对应混合路线确实取回了该情境，因此这两条路线能输出提案；漏检的方法不会从全池评审答案中补入它。

real-04 仍有这段历史互动的结构依据，但当前情节已进入新的调查动作，本轮没有为它强行补出继续争执的方案。“前文出现过”与“现在应当继续”已在输出中分开，但后者仍依赖导入的 AI 审核，尚无自动事件状态判别器。

两个公开对照也保留了正确的信息边界：未拆信时不知道暗号内容；拆信并复述后才明确知情。但“知道暗号”没有因此变成“揭秘”“禁忌知识”或“织物传书”的母题结构。它首先是信息获取、载体与人物知情状态的变化。

## 审核中修正的三个问题

1. **事件顺序回退。** 初始提案在交接已经结束之后仍写“接收时”。复核后改为安置刚收到的物品，不改变匹配等级。
2. **把一般调查提升为母题片段。** real-04 的检查与解释假说确有依据，但《真相追寻》资料将触发阶段写为发现疑点并决定追查到底；前文缺少后一个条件。由“特定片段”改为“证据不足”，相应未来提案不再作为本母题输出。
3. **把缺证判成反证。** 公开暗号案例的传递者能说话，不能证明不存在威胁造成的禁声，也不能证明他就是信件作者或受害者。“织物传书”由“矛盾”改为“证据不足”。

初始审核与最终审核均保存在本地实验目录，检索参数和排序未因上述修订而改变。程序能核对引文位置和标签约束，不能仅靠引文准确就保证语义判断正确。

## 下一步

先把少量真实资料转成有来源的“阶段／情境卡”，验证后再决定全库统一格式。每张卡应明确：承接所需的关系与状态、已经完成的动作、对应的具体阶段、仍缺的条件、允许推进的动作，以及人物知情依据。普通的信息传递、检查线索等动作应有自己的情境层，不靠放宽某个母题的定义来容纳。

下一轮用新的连续片段，分别放入明确匹配、仅有部分条件和明确不匹配的案例；冻结卡片后再评估。重点检查事件推进和拒绝不适合的推荐，并保留整段前文与结构化状态两条检索路径作对照。
