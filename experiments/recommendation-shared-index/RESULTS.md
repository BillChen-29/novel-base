# 共享索引与十二卡对照结果

2026-11-05。本轮完成知识向量复用、项目查询隔离及扩库后的候选审核。推荐核心仍默认使用原四卡；十二卡为独立实验目录。接口见 [README.md](README.md)。

## 缓存确实减少了编码

先完整校验上一轮十二个截点的实际编码产物，导入四份共享知识向量和十二份独立查询快照，没有调用模型。三种方法重放的排序、提案内容、动作门槛、采纳及版本失效结果与上一轮一致。来源改变使请求、提案 ID 和批次散列相应变化，未声称完整会话字节相同。

然后冻结十二卡目录及十四个截点，再运行已缓存的本地 EmbeddingGemma 模型：

| 项目 | 实际结果 |
|---|---:|
| 新知识文档编码 | 8 |
| 独立项目／版本查询编码 | 14 |
| 本轮输入编码总数 | 22 |
| 当前目录文档的缓存命中次数 | 160 |
| 再次读取十四个快照的新增编码 | 0 |

按上一版每个截点重编码十二卡加一查询的方式，同样输入需要 14 × 13 = 182 次输入编码；这个数字是工作量对照计算，没有另外运行一次全量模型基线。本轮十四次模型进程墙钟合计约 13.07 秒，包含进程启动；不据此报告速度倍数。目录变化也会使已有查询快照失效，所以原十二条查询本轮仍重新编码。

全部得到 768 维向量。再次组装十四个产物时无需模型，且每个产物与其第一次组装结果完全一致。十个公开案例另建输入目录，在逐字节核对输入后复用向量；三种方法的结果和五个完整公开会话均与完整实验的对应部分一致。

## 扩库后的推荐结果

原七个原创连续截点、三条同义改写、两段旧真实前文保持原样；再加入两处真实小说的更早顺叙截点。后两处来自同样两本小说的重叠场景，不是新增独立故事。基础事实和动作状态重新审核后，分别成立为检查待进行、监控与地图对照正在进行。

三种方法均只取前两名。编码前已冻结目录和查询，没有按排名改词。

| 样本 | 关键词可用提案 | 向量可用提案 | 混合可用提案 |
|---|---:|---:|---:|
| 原七个原创截点 | 5 | 5 | 5 |
| 三条同义改写 | 0 | 2 | 2 |
| 两段旧真实前文 | 0 | 0 | 0 |
| 两个新真实截点 | 0 | 0 | 0 |

四卡池中，向量与混合曾在三条同义改写上各得到三个提案；十二卡池中下降到两个。这次扩库揭示了候选名额分配问题，不能把缓存成功等同于推荐质量提升。

只审核各方法实际取回且动作允许的实例。十二份不同审核包共 57 条条件及 57 条知情判断，由本轮 AI 重新阅读：32 条支持、5 条矛盾、20 条证据不足。条件和角色知情分别判定，格式与精确引文再由程序核验；程序校验不证明语义判断必然正确。没有修改旧审核的散列后直接套用。

关键词、向量、混合分别取回 20／28／28 张卡，送审 7／10／9 个实例。新卡中实际送审的是试炼指引、禁忌知识读取、时限调查三类；均未形成可用提案。其余五张新增卡只参加了排序竞争，尚未验证正负例。三种方法仍各执行四次采纳，事实不变，四次适用的旧版本采纳均被拒绝。

## 具体失败及下一步

同义取件例中，向量和混合把“试炼指引”“禁忌知识读取”排在前二名，适合的通用载体使用卡在第四名。第一张缺少试炼前提，被审核拦住；第二张操作是读取，与该例当前的使用动作不符。可用卡没有进入条件审核。

新监控对照例中，前两名分别对应使用和回应；可匹配检查动作的线索卡在第三名，因此没有实际实例送审。这是检索漏入审核，不能记成条件审核否定了它。新尸体例中，关键词找回线索卡，但“存在具体尚未查明的问题”证据不足；向量找到时限卡，正文没有为本任务设定明确截止期限。这些都保留未放行。

[budget-diagnostic.json](budget-diagnostic.json) 保存只读诊断：在完整排序中先去掉与当前可用动作不兼容的卡，再取两名，可让上述两个例子的相关卡进入候选。但是这还不是正式检索策略，也没有将额外候选偷偷补入本轮结果；相关卡仍须接受条件审核。

下一轮应优先验证**动作类型过滤、候选名额分配和重排**，并用真实正负例检验扩大后的资料池。本轮证据优先支持修正操作类型错位与候选名额分配；更大模型或不同维数是否有收益，需要另行对照。

## 验证与限制

新增 25 项测试，完整 Python 回归 **553 项通过**。代码复核发现的缺失项目范围输入已修复；安全复核要求的私有文件权限及目录替换保护也已修复。所有新代码经复核通过。原推荐核心与原始 271 份资料保持不变。

当前使用 JSON 内容索引和不可变快照，仍需全量读取与校验索引，尚无大规模数据库、自动回收或并发合并。实验使用当前 AI 导入审核，不调用额外模型接口；原文、向量和完整运行记录留在被忽略的 `runtime-data/recommendation-shared-index/`。具体文件散列和校验记录见 [verification.json](verification.json)。
