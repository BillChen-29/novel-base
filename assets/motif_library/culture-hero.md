# 母题：文化英雄 (Culture Hero)

## 一句话定义
一个具有神性的人物，为人类获取或首先发明了重要的文化成果（火、农业、文字、医药等），使人类从蒙昧走向文明。他们是人类集体力量的神话化身。

## 叙事结构模板

1. **蒙昧时代**：人类处于原始状态，缺乏基本的生存技能。
2. **英雄的出现**：一个具有超凡能力的人物出现（半神半人）。
3. **文化创造**：英雄为人类发明了火、弓箭、农业、文字等关键文化成果。
4. **与自然的搏斗**：英雄在创造过程中与自然力量（洪水、猛兽、疾病）搏斗。
5. **文明的开端**：人类因英雄的贡献而进入文明时代。

## 承载的常见命题

- 集体力量的象征：文化英雄不是个人，而是整个氏族创造力的化身
- 文明的代价：每一项文化创造都伴随着艰辛与牺牲
- 人与自然的关系：文化英雄标志着人类开始主动改造自然
- 民族认同的根基：文化英雄是民族文化认同的核心符号

## 可搭配的意象池

- 火的发现与保存
- 弓箭的发明
- 农业的起源（种子、耕作）
- 文字的创造
- 医药的发现

## 常见情境原型

- **盗火者**：英雄从神那里偷取火种，造福人类（普罗米修斯）
- **射日英雄**：英雄射落多余的太阳，拯救被炙烤的大地（后羿）
- **治水英雄**：英雄治理洪水，拯救苍生（大禹）
- **农耕英雄**：英雄发明农业，使人类定居（神农、后稷）
- **医药英雄**：英雄遍尝百草，发明医药（神农氏）

## 经典案例

- **后羿射日**：射落九个太阳，拯救被炙烤的大地
- **神农尝百草**：发明农业和医药
- **仓颉造字**：创造文字，开启文明
- **燧人氏钻木取火**：为人类带来火种
- **大禹治水**：治理洪水，划定九州

## 不适用场景

- 故事不涉及文化创造或文明起源时
- 主题偏向个人成长而非集体命运时
- 叙事聚焦于日常生活而非英雄传奇时
